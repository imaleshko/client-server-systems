# Розробка інтернет клієнт-серверних систем

Лабораторні роботи з дисципліни "Розробка інтернет клієнт-серверних систем"

## Структура

| Лабораторна      | Тема                                                    | Зміст                                         |
|------------------|---------------------------------------------------------|-----------------------------------------------|
| [`lab2`](./lab2) | Введення даних, рядки, слайси, map, математичні функції | 15 завдань                                    |
| [`lab3`](./lab3) | Умовні оператори та цикли                               | 10 завдань                                    |
| [`lab4`](./lab4) | Функції, рекурсивні алгоритми, замикання                | 12 завдань                                    |
| [`lab5`](./lab5) | Модулі, тести                                           | пакет `generator` і консольна програма `main` |

## Запуск

**lab2 – lab4:** кожна лабораторна є окремим Go-модулем. Завдання викликаються з `main.go`, потрібно розкоментувати потрібний `taskN()` і запустити:

```bash
cd lab2
go run .
```

**lab5:** workspace з двох модулів:

```bash
cd lab5/main && go run .                # консольне меню
cd lab5/generator && go test -cover     # тести
```

## Вимоги

Go 1.27+
